# 🧮 Simple Calculator Using Python

## 📌 About the Project
This project is a simple calculator developed using Python. It performs basic arithmetic operations and includes input validation and error handling.

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Repeat calculations without restarting the program
- ⚠️ Handles invalid number inputs
- 🛡️ Prevents division by zero
- 🚪 Exit option after each calculation

## 🛠️ Technologies Used
- **Programming Language:** Python
- **IDE:** Python IDLE

## 📋 Requirements
- Python 3.x

No external libraries are required.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the `calculator.py` file using Python IDLE or a terminal.

```bash
python calculator.py
```
