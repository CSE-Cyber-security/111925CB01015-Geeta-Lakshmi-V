# Fibonacci Series Generator 🐍

## About the Project

The Fibonacci Series Generator is a simple Python program that generates the Fibonacci sequence based on the number of terms entered by the user.

In this sequence, each number is the sum of the previous two numbers.

**Example:** `0, 1, 1, 2, 3, 5, 8, 13, 21...`
## Features

- Accepts the number of terms from the user.
- Generates the Fibonacci series using a `for` loop.
- Handles non-positive input.
- Simple and beginner-friendly code.

## Technologies Used

- Python 3
- Built-in `input()` and `print()` functions
- Conditional statements and loops

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `python fibonacci.py`

5. Enter the number of terms when prompted.

## Sample Output

Fibonacci Series:
